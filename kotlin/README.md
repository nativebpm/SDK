## Fluent API & Workflow-as-Code

The SDK provides a high-level Fluent Client API and a type-safe Workflow-as-Code builder.

### Fluent Client Initialization
```kotlin
import com.nativebpm.client.Client

val client = Client("http://localhost:8080", "your-api-token")
```

### Defining a Workflow (Workflow-as-Code)
```kotlin
import com.nativebpm.client.builder.Workflow
import com.nativebpm.client.builder.Workflow.V

val workflow = Workflow("my-process", "My Process")
workflow
    .when(V("isPremium").eq(true)).then { b ->
        b.user("vipService", "VIP Support", mapOf("assignee" to "vip_manager"))
    }
    .Else { b ->
        b.service("notify", "Send Email", "email_topic")
    }
```

### Deploying & Starting Workflows
```kotlin
// Deploy
val definition = client.deploy(workflow)

// Start process instance
val instance = client.instances().start(definition.id)
    .withBusinessKey("BIZ-101")
    .withVariable("isPremium", true)
    .send()
```
